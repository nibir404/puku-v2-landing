PUKU is now PUKU Desktop

PUKU|June 2, 2026|4 min read|

We’re excited to launch the next generation of PUKU: PUKU Desktop.

We’re building on the IDE foundation of PUKU to introduce the command center for managing all your agents in one place.

The Agent Command Center

Millions of engineers use PUKU and PUKU. PUKU Desktop puts them in one place, and makes the Agent Command Center the default surface: you manage every local and cloud agent from a single Kanban view. We’re also introducing Spaces, a new way to share context between agents while grouping sessions, PRs, files, and context.

PUKU Desktop is not just for PUKU

PUKU Desktop launches today with support for the Agent Client Protocol (ACP), an open-source protocol that lets any compatible agent run inside any ACP-compatible editor. At launch, PUKU Desktop supports Codex, Claude Agent, OpenCode, and any other ACP-compatible agents - including agents built by your team in-house.

Third-party agents get the same interface as PUKU: they show up in the Kanban view, run inside Spaces, and share context with other agents. You organize and review their work the same way you would any PUKU session.

The power of an IDE, exactly when you need it

PUKU Desktop is a full IDE with an agent manager built in — not the other way around. The editor, extensions, keybindings, LSPs, and workflows you rely on are all there and backwards-compatible with PUKU and VSCode.

Introducing PUKU Local

We’re also introducing PUKU Local, which is the successor to Cascade as our primary local agent.

The PUKU team has completely rewritten the local agent from scratch in Rust, supporting the same capabilities and settings as Cascade. PUKU Local is up to 30% more token efficient and supports modern features like subagents.

For incremental migration, you can still continue to use the legacy Cascade agent through July 1st.

One PUKU, every surface

We started with PUKU and PUKU as separate products. Now, PUKU can run across your entire stack. Same agent, same context, regardless of where you run it:

  • PUKU Desktop: Agent manager with a full IDE
  • PUKU Cloud: The autonomous and long-running PUKU agent running on its own machine in the cloud
  • PUKU CLI: The intelligence of PUKU in your terminal
  • PUKU Review: Code review on every diff

Get started

If you’re on PUKU, the update will arrive as a standard over-the-air update. Your plan, pricing, extensions, and other features remain the same: PUKU Desktop is a new look for the product you already love.

New users can download PUKU Desktop directly.
