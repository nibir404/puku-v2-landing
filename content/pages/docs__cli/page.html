Core CLI Commands

Essential commands for managing agents, context, and settings.

puku run

puku run ""

Launches an autonomous task agent with the specified prompt and options.

puku init

puku init

Initializes Puku configuration and indexes the repository AST graph.

puku task

puku task list / status

Monitors running background agent tasks and inspects active logs.

puku config

puku config set / get

Manages API keys, model preferences, and environment parameters.
