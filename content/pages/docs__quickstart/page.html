5-Minute Onboarding Steps

Follow these quick steps to get up and running.

Step 1

Install Puku

Download the Puku App or install the CLI via terminal.

Step 2

Authenticate

Run `puku login` to connect your account credentials.

Step 3

Index Repository

Navigate to your code repo and run `puku init` to index the AST.

Step 4

Run Your First Task

Execute `puku run "Add unit tests for user service"` and inspect the generated PR.
